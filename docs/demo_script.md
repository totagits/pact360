# guided demo script

This guide provides a walk-through for users testing **PACT360** in sandbox/demonstration mode.

## Step 1: Sign-In with Demo Profiles
1. Open the login page.
2. Select any Sandbox Profile at the bottom of the page (e.g. `Super Admin`, `Asset Manager`).
3. Click "Sign In" to be routed directly to the Executive Dashboard.

## Step 2: CSV Data Migration
1. Select "Assets Register" in the side navigation panel.
2. Click the "Data Migration (Excel/CSV)" sub-tab.
3. Upload a sample CSV containing column headers: `name`, `assetTag`, `serialNumber`, `purchaseCost`, `purchaseDate`, `category`, `office`, `donor`, `grant`, `project`.
4. Review the row-by-row error maps. If valid, click "Commit Import".

## Step 3: Physical Count Campaigns
1. Click the "Physical Audits & Counts" sub-tab under Assets Page.
2. Click "Start Audit Campaign" to launch a campaign targeting specific offices.
3. Click on the campaign name to open the count checklist.
4. Log count verifications ("Verified", "Missing", "Damaged") and review the variance reports.
