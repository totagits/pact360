# Service Level Agreement (SLA) Template

**Document Reference**: SLA-PACT360-PLAN-LBR  
**Client**: Plan International Liberia  
**Service Provider**: PACT360 Technical Solutions  

---

## 1. Scope of Agreement
This agreement covers support, maintenance, and hosting availability for the **PACT360** asset management application.

## 2. Service Availability Target
- **Uptime Metric**: Monthly availability of 99.9%.
- **Exclusions**: Scheduled maintenance windows, force majeure events, country-wide internet routing outages.

## 3. Incident Severity Levels & Response Targets

| Severity | Description | Response Time | Workaround Time |
|----------|-------------|---------------|-----------------|
| **P1 - Critical** | Main application offline, logins blocked. | < 30 mins | < 4 hours |
| **P2 - High** | Assets import failing, report downloads broken. | < 2 hours | < 12 hours |
| **P3 - Medium** | Incorrect tag prefixing, styling errors. | < 8 hours | < 48 hours |
| **P4 - Low** | Minor UI suggestions, document typos. | < 24 hours | Next release |
