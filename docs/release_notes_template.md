# TOTAG PACT360: Release Notes

**Version**: v1.0.0-LBR-ITT-044  
**Release Date**: June 3, 2026  
**Target Environment**: Google Cloud Run Production  

---

## What's New in this Release

### Core Enhancements
- **Dynamic White-Labeling**: Admins can now customize the app name, system tagline, and primary HSL/Hex theme colors dynamically from the database.
- **Physical Counts & Verification Campaign**: Audit registries can launch count campaigns, reconciliate inventory lists in real-time, and download discrepancy maps.
- **Asset Data Migration (CSV Import)**: CSV data upload validation interface parsing columns and identifying formatting errors row-by-row with database rollbacks.
- **Auditing Integrity**: Added set-null deletion safety and logs audit events mapping user profile parameters.
