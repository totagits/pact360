# PACT360 User Manual

Welcome to **PACT360: Project Asset, Contract, Tracking, and Lifecycle Management System**. This user guide explains how to perform daily operations.

---

## 🧭 Navigation & Dashboard

When you sign in, the main **Executive Dashboard** aggregates active totals:
- Net asset book values are depreciated automatically using the Straight Line method.
- Alert boxes flag expiring warranties, overdue generator/vehicle work orders, and contracts expiring within 30 days.
- **Recent Activities** lists the latest configuration actions.

---

## 📦 Asset Operations

### 1. Registering an Asset
1. Go to **Assets Register** and click **Add Asset**.
2. Fill in the purchase dates, initial acquisition cost (USD), warranty terms, and project/grant linkages.
3. Once submitted, the system auto-generates a unique asset code (e.g. `PLAN-AST-LAP-0023`) based on its category.

### 2. Asset Custody & Assignments
1. On an asset's profile page, click **Assign Custodian**.
2. Select the staff user, return due date, and initial condition.
3. Toggling assignment updates the status to **Assigned** and triggers an in-app alert for that staff user.
4. To return the item, click **Return Asset**, input the final returned condition (Good, Fair, Poor), and submit to return it to the central store.

### 3. Asset Transfers
1. Click **Transfer Asset** on any item.
2. Choose the transfer target (a different Project or a different physical Office).
3. Transfers generate a "Pending Approval" record. The Head of Operations receives a notification to approve or reject the request.

---

## 🔧 Maintenance Operations

1. Go to **Maintenance Log**.
2. Select **Issue Work Order** to schedule servicing. Specify the asset, scheduled date, priority, and assign it to a local service partner (e.g. Liberia Auto Services).
3. An officer clicks **Start** when the work begins (updating the asset status to "Under Maintenance").
4. On completion, click **Close Out**, tick the checklist points, enter the final cost, and submit.
