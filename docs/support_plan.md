# PACT360: Support Plan

This document outlines the support infrastructure, tiers, response times, and escalations for **PACT360** at Plan International Liberia.

## Support Tiers

### Tier 1: Local IT Support / Helpdesk
- **Responsibility**: First-line support, password resets, login issues, general usability questions.
- **Handling**: Local Country Office IT personnel.
- **Response Time**: Within 4 hours.

### Tier 2: System Administrators
- **Responsibility**: Configuration changes, user role adjustments, report queries, data correction.
- **Handling**: Appointed System Administrators / Database team.
- **Response Time**: Within 12 hours.

### Tier 3: Core Developer Support (Vendor)
- **Responsibility**: Code bug fixes, performance enhancements, database restructuring.
- **Handling**: Vendor / Software Development Partner.
- **Response Time**: Within 24-48 hours.

## Escalation Matrix

1. **Incident Logged**: User reports issue via helpdesk portal.
2. **First Triage**: IT Officer handles within 4 hours. If unresolved, escalates to SysAdmin.
3. **Second Triage**: SysAdmin reviews database logs and settings. If code-related, escalates to Dev Team.
4. **Hotfix**: Developer issues patch via CI/CD to Google Cloud Run.
